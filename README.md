# Model-View

**Model-View** is a collaborative web application where users can upload datasets and define real-world problems for others to solve with predictive models. It’s designed to make learning and applying data science more engaging through hands-on challenges and friendly competition.

## Project Overview

The platform is being built in phases, starting with a foundation that includes user authentication, dataset upload capabilities, and a simple UI to view problems and submissions.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS  
- **Backend:** Python, Flask  
- **Database:** SQLite (for now)
